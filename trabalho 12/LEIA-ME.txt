EXERCICIOS JAVA - API NIO

Conteudo:
- Exercicio1.java: cria diretorios e grava relatorio com Files.writeString().
- Exercicio2.java: le servidor.log com Files.lines() e lista erros.
- Exercicio3.java: le produtos.csv com Files.readAllLines() e calcula o inventario.
- Exercicio4.java: percorre a pasta src com Files.walk() e lista arquivos .java.
- Exercicio5.java: padroniza clientes_bruto.txt e grava clientes_padronizado.txt.

Como executar:
1. Abra a pasta no IntelliJ, Eclipse ou VS Code.
2. Cada exercicio possui sua propria classe main.
3. Nos exercicios 2, 3 e 5, deixe os arquivos de entrada na pasta de trabalho do projeto.
4. No exercicio 4, execute a partir de uma pasta que contenha uma subpasta chamada src.

Requisito:
- Java 15 ou superior para text blocks e Path.of().
- Java 11 ou superior para String.isBlank() (Java 15+ atende a todos os recursos usados).
